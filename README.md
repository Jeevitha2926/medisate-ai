# MediSate AI 💊

## Medicine Information and Interaction Screening App

MediSate AI is a Streamlit-based application designed to provide educational information about medicines and help users screen for potential medicine interactions.

## Features

- 💊 Enter one or more medicine names
- 🔎 Analyze medicines
- 📋 View medicine information
- ⚠️ Display important warnings
- 🔄 Screen for potential medicine interactions
- 🌐 Accessible through a web browser

## Technologies Used

- Python
- Streamlit
- Requests
- GitHub
- Streamlit Community Cloud
